Egy kód író program, ami a megadott karaktereket egy "módosító karakter" segítségével számokká alakít.

funkció:
    titkosítás: Az alapértelmezett vagy felhasználó által megadott abc alapján érvényes karakterek
        mind sorszámot kapnak, azok abc-ben elfoglalt helye alapján. Ha a felhasználó beír egy
        karaktersort titkosítani, akkor az abc és még egy érvényes "módosító karakter" segítségével, egy szám sor jön létre.
        Ezt a számsort az output.txt-be is menti a program (Egyszerre csak 5 outputot lehet menteni, ha több van a program kiüríti a fájlt)

    fordítás: A felhasználó által megadott számsort az ahhoz tartozó "módosító karakter" segítségével visszaalakítja szöveggé.
        Az output.txt-be ez is mentésre kerül.
    
    saját abc megadása: Az alapértelmezett abc kicserélhető a felhasználó által.

    alap abc visszaállítása: Az alapértelmezett abc visszaállítható.

Továbbá a program telepítője (.exe fájl telepítése) elérhető a setups mappában
