Egy fogócska játék ahol egy búvárral halakat gyűjtesz és egy cápa kerget

A pályán a 2 mozgó karakteren és a halakon kívül van 2 teleport kapu (különböző színű vonalak
melyekhez érve mind a játékos és a cápa random pozícióra teleportálódik)

a program főbb részei:

-a játék
-a program telepítője (lásd: setups mappa)
-egy visszajátszás rendszer ami a periódikusan mentett és titkosított játékos pozíciókat rajzolja ki
-egy rekord mentési rendszer szintén titkosítva mentve
-titkosítás: a "kód író" programom módosított, gui nélküli változata
